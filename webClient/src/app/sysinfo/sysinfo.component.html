System Resources

2
Browser Compatibility

Zowe Desktop works best with modern browsers. Check the Client tab to verify your browser version and ensure cookies and JavaScript are enabled.

3
Network Connectivity

The Network tab shows server interfaces and ZSS agent connectivity. Use this to verify connectivity and diagnose issues connecting to mainframe services.
